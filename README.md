# TileFlow
Contact: Weiling Yang (2954427597@qq.com)

TILEFLOW is a high-performance GEMM library for irregular GEMM workloads on CPUs with matrix units, which alleviates computation–data movement mismatches by optimizing packing strategies and NUMA-aware data placement.

# Reference
Weiling Yang, Jianbin Fang, Dezun Dong, Chencheng Deng, Runxi He, Junwen Zhang. TILEFLOW: Data-Movement-Centric Optimization for Irregular GEMM on Matrix-Unit CPUs (SC 2026).

# Software dependences
GCC >= 13.0, OpenMP, numactl, MKL 20250300
